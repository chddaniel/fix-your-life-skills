# Anti Vision

Build an honest negative reference point without catastrophizing, shaming, or inventing consequences. The user supplies the content; you supply the sequence and specificity.

## Establish the present trajectory

Ask what the user repeatedly complains about or tolerates. Anchor each answer in current behavior rather than aspirations.

## Describe the ordinary future

Guide the user through an average weekday five years from now if the relevant pattern continues. Cover only dimensions that matter to them, such as work, health, relationships, attention, money, environment, and self-respect.

Ask for sensory and behavioral detail: where they wake, what happens during the day, who is present, and how the evening feels. Repeat for a longer horizon only when it produces a materially different cost.

## Expose the bargain

Explore what opportunity closes, what experience is missed, which identity must be surrendered to change, and what current behavior protects. Treat feared outcomes as possibilities rather than forecasts.

## Compress it

Draft two or three one-sentence anti-visions using the user's own concrete language. Each should state the trajectory and its unacceptable cost without melodrama. Let the user choose or rewrite one.

Calibrate the result: it should feel plausible on the present trajectory and unacceptable to the user. If it feels cinematic, reduce the claim. If it feels abstract, return to the ordinary-day details.

Then identify one repeated behavior that moves toward that future and one immediate interruption.

## Output

- Current tolerated pattern
- Five-year ordinary day
- Unacceptable cost
- Identity or protection maintaining it
- Anti-vision sentence
- Immediate interruption
