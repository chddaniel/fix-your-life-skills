# Goal Steering

Treat a goal as a lens for noticing and choosing, not a promise that reality must obey. Help the user improve their steering rather than merely demand more discipline.

## Define the destination and horizon

Ask what outcome they want, why it matters now, and the shortest meaningful review horizon. Separate outcomes they influence from outcomes they control.

## Map the current loop

Identify:

1. Goal: the current direction
2. Act: the repeated action or strategy
3. Sense: the evidence being collected
4. Compare: the standard used to judge progress
5. Adjust: how the next action changes in response

Locate missing or weak links. Common failures include vague goals, actions too large to repeat, delayed feedback, vanity measures, and repeating without adjustment.

## Improve the steering system

Choose one leading indicator and one outcome indicator. Set a review cadence appropriate to the feedback speed. Define the next smallest informative action and what result would trigger continuing, changing, or stopping it.

Change one important variable per cycle where practical. If several variables change at once, say that attribution will be weak.

When opportunity is the constraint, identify a test that increases access or information rather than blaming personal agency. When the goal itself appears borrowed or unwanted, pause and recommend a revealed-goal or vision audit.

## Output

- Direction and horizon
- Current steering loop
- Broken link
- Leading and outcome indicators
- Next informative action
- Continue/change/stop rule
- Review date
- What this cycle cannot establish
