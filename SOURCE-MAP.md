# Source Map

Primary source: Dan Koe, ["How to fix your entire life in 1 day"](https://letters.thedankoe.com/p/how-to-fix-your-entire-life-in-1), published December 23, 2025.

Original X Article post: https://x.com/thedankoe/status/2010751592346030461

This map records how the article was transformed. It is not a reproduction or claim that Dan Koe authored or approved these skills.

| Source concept | Skill implementation | Adaptation decision |
|---|---|---|
| Outcomes follow from the lifestyle and identity that repeatedly produce them | `$minimum-viable-vision`, `$identity-loop-audit` | Tests whether the user wants the producing lifestyle, then turns identity claims into small behavioral evidence. |
| Repeated behavior may serve a different goal than the one a person states | `$revealed-goal-audit` | Requires a recent observable episode and competing hypotheses so the agent cannot declare a hidden motive as fact. |
| Identity forms and defends a self-reinforcing perception-action loop | `$identity-loop-audit` | Maps one loop, tests evidence for and against it, and chooses a small break point. |
| People perceive life through changing mental models and stages | No standalone skill | The article presents this mainly as explanatory context. Turning a developmental hierarchy into an agent judgment about the user would add risk without a clear task. |
| Intelligent progress resembles a cybernetic act-sense-compare-adjust loop | `$goal-steering` | Converts the explanation into an observable feedback and course-correction system. |
| A reset moves through dissonance, uncertainty, and discovery | `$life-reset-day` | Uses this as pacing, while treating discovery as provisional rather than guaranteed. |
| Morning reflection produces an anti-vision and a minimum viable vision | `$anti-vision`, `$minimum-viable-vision` | Separates the negative and positive directions so either can be used independently. |
| Prompts during the day interrupt unconscious behavior | `$autopilot-interrupts` | Generates context-aware, reminder-ready prompts but never schedules them silently. |
| Evening synthesis turns insights into nested time horizons | `$life-gameboard` | Connects a one-year outcome, one-month project, daily levers, and constraints. |
| The complete exercise should be done by the reader, not outsourced to AI | All skills | The agent facilitates, challenges vagueness, and structures answers; it does not invent the user's inner truth. |

## Fidelity boundary

The set preserves the article's actionable logic while deliberately omitting long quotations, biographical examples, third-party quotations, and claims that the framework guarantees transformation. Users should read the original article for Dan Koe's complete reasoning and expression.
